## 📌 Project 1: HR Analytics Dashboard

### 🎯 Objective
The objective of this project is to analyze employee attrition and workforce data to identify patterns and trends that can help organizations understand employee turnover and make better HR decisions.

### 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Microsoft Power BI
- DAX

### 📊 Key Analysis
- Analyzed overall employee attrition.
- Studied attrition across different departments.
- Examined attrition by age group and gender.
- Analyzed employee attrition based on job roles.
- Explored the relationship between job satisfaction and attrition.
- Compared monthly income of employees who stayed and those who left.

### 📈 Dashboard Features
- Employee and attrition KPIs.
- Department-wise attrition analysis.
- Age-group and gender-based analysis.
- Job satisfaction analysis.
- Interactive filters and slicers.
- Visual representation of workforce trends.

### 📁 Project Files
- `data/` – HR employee dataset.
- `python/` – Python analysis script.
- `visualizations/` – Generated charts.
- `powerbi/` – Power BI dashboard file.

## 📌 Project 2: Netflix Exploratory Data Analysis (EDA)

### 🎯 Objective
The objective of this project is to explore and analyze Netflix content data to understand the distribution of movies and TV shows, content ratings, and trends in Netflix's content library.

### 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib

### 📊 Key Analysis
- Explored the Netflix titles dataset.
- Compared the number of movies and TV shows.
- Analyzed content ratings and their distribution.
- Examined trends and patterns in Netflix content.
- Created visualizations to understand the dataset.

### 📈 Visualizations
- Movies vs. TV Shows distribution.
- Content ratings distribution.
- Comparison of movies and TV shows.

### 📁 Project Files
- `netflix_titles.csv` – Netflix dataset.
- `netflix_eda.py` – Python analysis script.
- `visualizations/` – Generated charts and graphs.
